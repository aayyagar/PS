# AD_DNS_Toolkit

A full PowerShell toolkit for Active Directory and DNS Management. Supports Windows Server 2016, 2019, 2022, Azure, AWS, and GCP.

## Contents
- Active Directory Inventory
- Active Directory Backup & Restore
- DNS Zones Backup & Restore
- Health Checks
- Stale Records Cleanup
- Auto-Detection of Cloud Environment

## Usage
Use the Launcher Script `Launcher\AD-DNS-Tool.ps1` for easy menu-based operations.
